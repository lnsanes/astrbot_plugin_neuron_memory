# astrbot_plugin_neuron_memory

把机器人的记忆做成**连续权重**而不是"存了/删了"的二元状态。

记得清楚的事权重高，会主动想起来；久不提起的事权重衰减，逐渐想不起来；**但永远不会真正删除**——只要它特意翻，还能翻到，只是会告诉你「这条我快忘了」。

## 核心机制

### 1. 权重与衰减

```
每周...  每天 04:00 执行一次衰减

w = w * exp(-days / half_life)
half_life = 3 + 30 * importance      // 3 ~ 33 天
w 下限 = 0.01                         // 不会归零，永远留一线
```

写一条新记忆时 `w = 0.9`。

### 2. 反复提起会增强

新记忆写入前，先和最近 800 条比字面相似度（bigram 余弦）：

```
sim >= 0.85   →  认为是同一件事，合并：
                  weight += 0.12（上限 1.0）
                  mention_count += 1
                  importance 取两者最大值
sim <  0.85   →  新建一条
```

### 3. 永久记忆要模型点头

达到阈值不会自动升永久，而是**让模型判断值不值**：

```
mention_count >= 3  且  weight >= 0.92  且  还不是永久
        ↓
异步调 LLM 判断（不阻塞消息处理）
        ↓
  「永久」→ pinned = 1，weight 锁 1.0，从此不衰减
  「普通」→ 什么都不做，继续按半衰期掉
```

判定用的 prompt 刻意收窄，只让它回答两个字：

```
判断标准：长期有效的核心事实、重要关系、承诺、身份信息、
反复出现的偏好或约定才算；临时闲聊、一次性事件、
可再查的信息都不算。
只回答两个字：永久 或 普通。
```

### 4. 检索

```
score = 余弦相似度 * (0.3 + 0.7 * weight)
```

按权重分档决定怎么注入：

| 权重 | 处理 |
|---|---|
| ≥ 0.5 | 直接注入「你想起来的事」|
| 0.2 ~ 0.5 | 注入并标注「有点记不清了」|
| < 0.2 | 不主动注入（= 忘了），但深查可及 |

### 5. 认人

问「我是谁」「你记得我吗」这类问题时，query 里会出现「我/你/主人/谁/称呼/名字/身份」。

程序检测到这些指代词，**先把人物画像拉出来放到第一位**（浅查给前 420 字，深查给全文），再接正常的相似度检索。

因为字面匹配是有盲区的：问「我是谁」和记忆里的「lnsanes」一个字都不重叠。

## 提供的工具

| 工具 | 作用 |
|---|---|
| `recall_memory` | 翻自己的记忆。`deep=true` 连快忘掉的一起翻，并提示哪些已经模糊 |
| `memorize` | 主动记一条（带 importance 参数）|

## 消息采集

`@filter.event_message_type(EventMessageType.ALL)` 钩子，**所有消息都记**，不管机器人有没有回话。

按发送者定 importance：

| 来源 | importance |
|---|---|
| 主人说的话 | 0.65（长句 0.8）|
| 对它说的（@它 / 带它名字）| 0.6 |
| 群友闲聊 | 0.3（长句 0.4）|

过滤：长度 < 4、以 `/` `【` `[` `(` 开头的跳过。

**为什么用 `event_message_type` 而不是 `on_llm_request`**：后者只在机器人真的要开口回话时才触发。如果群里限定了只有主人能唤醒它，那绝大多数消息根本不进 LLM，全被漏掉。

## 管理页面

提供 AstrBot Plugin Pages（`pages/dashboard/`）：

- **知识图谱**：节点 = 实体，边 = 关系，永久记忆的实体描金边，点节点看关联记忆
- **记忆列表**：按权重排序，搜索、展开详情（权重 / 重要度 / 访问次数 / 半衰期）

## 数据

`data/plugin_data/neuron_memory/memory.db`（SQLite）：

```sql
memories      记忆本体（content / grams / weight / importance / pinned / mention_count）
entities      实体（name / etype）
relations     实体关系（src / dst / rel / weight）
mem_entities  记忆 ↔ 实体 关联
```

## 配置

| 键 | 默认 | 说明 |
|---|---|---|
| 衰减时刻 | 04:00 | 每日衰减的执行时间 |
| 注入条数 | 3 | 每次注入多少条记忆 |
| 半衰期基数 | 3 天 | `half_life = 3 + 30 * importance` |
